# Web host feasibility conversation transcript

Captured: 2026-10-04

Source: UR-Recomp platform-feasibility conversation.

The Web target was scoped around an Emscripten/WebAssembly host adapter while preserving the same authoritative simulation/product interfaces used by desktop. The plan covered browser lifecycle, persistence, input, audio, fullscreen and asset delivery, and kept Web-specific behavior outside authoritative game logic.

The work produced a concrete feasibility plan; publication of the associated PR was blocked at the time rather than the architecture being rejected.
