## Measured starting point and discriminating question

The actual RF054 case ZIP already has 1,806 original RF045 stack macro rows, 903 original RF044 bus-write rows, and 2,741 contiguous native RF047 events with 2,705 native helper reads. The original macro rows show real guest PB:PC without a local ordinal; the native helper rows show a reliable native-local sequence but **lack an executed guest opcode PC**. Rendered stderr/stdout ordering and the existing stale native interpreter-PC hint cannot repair either absence.

The authentic original NMI consumes status, saved PC and bank from its guest stack; native compiled RTI consumes status and skips guest PC/bank reads while continuing through the host return path. This is a known difference in *bus consumption*. Source/native post-wait gameplay equivalence, stack residue classification and the independent late sound-pointer $63 first consumed consequence are not thereby proven. The earlier original 82:82F0 sound upload and actual native 11:C774 helper evidence have **distinct original/native local clocks** and no justified global shift.

In native host frames 1017..1025, `QA01RF047NATIVE stage=opcode` joins the **same existing native sequence** as NMI/read records and preserves its overflow sentinel. - **RF047 reporting:** each new native `opcode` row must contain a six-digit executed guest PC, a tier `aot` or `interp`, and the recorder-local sequence. Generated AOT variants and the original/native genuine output must be inspected to ensure the marker actually executed, particularly original `82:82F0/82F2/82F6`.

`tools/qa01_rf045_rf047_causal_readiness.py <authentic-case-zip> --output <receipt.json>` reopens real `reference.log` and `native.log` bytes from the ZIP, hashes the archive and both original members, checks source macro/native event ordinal populations, validates optional actual decoded-PC markers and refuses truncated or forged native read PCs. Existing RF054 cannot be normalized into a genuine causal assessment: original RF044 writer records and script checkpoints still lack a *shared* source ordinal with RF045; native actual helper reads still lack their own proven executing PC; raw unmasked memory images are missing from that 18-member case archive. `qa01_causal_window.py` must remain fail-closed on these gaps.
