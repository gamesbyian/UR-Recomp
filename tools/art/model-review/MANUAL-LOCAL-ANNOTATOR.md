# Mobile-first original 1994 manual landmark marker (local source files only)

The same Pages five-parent 2026 GLB reviewer now links to `manual-landmarks.html`, a **standalone, private-in-browser annotator** for the four original Nintendo/DMA manual figure PNGs produced by `extract_manual_3d_reference_views.py` (#3166). This keeps model viewing and source observation separately inspectable on a mobile screen. No original image, crop bytes, or annotation is uploaded to the server or committed to the repo.

1. Run the authenticated PDF crop extractor once into a **new local folder** (it never replaces earlier evidence). On the phone, select `source-crops.json` and the four exact PNGs using the local file picker. Browser WebCrypto checks that **all four PNG byte SHA-256s** match the accompanying receipt, and the source Git blob identity matches the repo's fixed six-megabyte original 1994 USA manual. This client-only check is preliminary: a malicious receipt and matching forged PNGs still require the independently authenticated PDF pixel-replay validator for final acceptance.
2. Choose a printed figure and feature group: `wheel`, `hub`, `saddle`, `crown`, `fork`, `clamp`, or `crank`. Tap each truly visible point on the displayed PNG, or enter exact X/Y numeric source-crop pixels using accessible keyboard controls. Labels track the next required point, and coloured markers are client-only overlays. Alternately explicitly mark an entire feature unmeasurable with a real reason (occluded by printed track, cropped by page, etc.). **Do not guess invisible wheel ends or crank pedals.**
3. Supply reviewer label, nonzero pixel uncertainty and view-specific perspective/occlusion explanation. At least one group must be actually marked, and all seven groups for any exported figure must be measured completely or explicitly unmeasurable. Untouched views are omitted. The Save control produces `UR-ART4K-OFFICIAL-MANUAL-SPARSE-2D/1` JSON using the browser's Save File Picker when supported, or ordinary local browser download otherwise.
4. Run the merged `audit_manual_sparse_landmarks.py` (#3170) on that local JSON, the original PDF and original PNG directory. **Only this strict offline second pass** authenticates the original PDF as the tracked source Git blob; replays each original page/crop at 144 DPI; checks every PNG RGB pixel against the retained real PDF; checks the exact per-annotation crop SHA, coordinate bounds, omitted group reasons, and perspective uncertainty; and emits 2D projected measurements. It refuses physical 3D claims and will never normalize a view without a complete visible projected wheel.

This browser UI does not load user images into the existing original Mesen/2026 3D model rail, does not save candidate 3D meshes or send data to GitHub, and makes no claim that the printed 1994 manual figure was rendered from the exact original game's missing 3D production mesh/camera. The six-objective true Mesen24 scorer and owner visual veto remain authoritative. The figure tool is a *measurement workbench*, not automatic recognition or a new 3D reconstruction.
