## Cross-lane decisions, ownership and deadlines

1. **The CPU/APU producer supplies witnesses; QA01 independently judges them.** Neither edits the other's verdict. QA01 alone may propose updates to event census; one release QA owner controls [RELEASE-QUALITY-LEDGER.json](RELEASE-QUALITY-LEDGER.json). This queue never duplicates machine authority.
2. **Modern owns product bytes and Windows candidate creation; independent release QA** checks physical, disk, packaging and player journeys on those exact bytes. If no fifth agent is available, the integration owner schedules QA review after Modern submits immutable hashes, rather than promoting its own proof.
3. **Graphics owns raster/HD source.** The original likeness needs explicit human art approval despite past procedural 4× build/pose manifests. Widescreen world extension, HD art and 4K physical output are separate requirements.
4. **Integration owns shared queue edits, branch conflicts, workflow policy and merged-main checks.** Other agents update their specialist evidence and offer proposed queue changes in a PR description, not concurrent queue rewrites.
5. **No fixed deadline overrides evidence.** For each task record the hypothesis, cheapest test likely to change a decision, the negative outcome, stop criterion, and one next owner. Stop broad factory production until a bounded unknown demands it. [Cumulative factory yield](QA-CUMULATIVE-RESEARCH.md) recommends no general frontier run.

## Promotion, CI and safe stopping

- Run three-project source reuse preflight via `python3 tools/select_three_project_reuse.py --lane <lane> --include-conditional` before major implementation. Consume prior artifacts first and inspect one decision-bearing producer case instead of multiplying factories.
- Verify **first failed CI step on exact head**. Separate failed setup/evidence transport from guest failure; do not poll repeatedly. ROM-free unit/hygiene and workflow-specific exact checks must be reported as run/not-run/failed, never inferred.
- Preserve immutable ROM/SMV/controller, tool commit, actual compiled binary and original/native guest artifacts, hashes, clocks, complete raw images and explicit confidence category. Do not put private ROMs, image dumps or generated toolchains in a PR.
- Every handoff reports exact branch/commit, open PR, owner, next discriminator, checks and artifact links, failure evidence, unresolved risk and explicit HOLD/accepted gates. Temporary workflows and runners get retired after evidence intake.
- **Defer** optional cosmetics, editor courses, netplay, additional platforms, generic RE, redundant renderer/menu/save state subsystems and broad 45-course sweeps unless a proven blocker requires them.
