# Dragster presentation spatial/resource contract

Generated by tools/build_course_presentation_contract.py. This is a Widescreen-facing contract, not an editor-complete course format.

## World and camera extent

- Header dimensions 256 x 4 expand to a runtime coarse grid of 1024 x 16 64-unit sectors.
- Dragster world extent is 65536 x 1024 world units; X range is 0..FFFF, Y range is 0..03FF.
- Camera configuration uses matching masks 0D49=FFFF and 0D47=03FF.
- Spawn is (1088, 800); the historical finish-X probe 25278 falls inside this extent.

## Two-level spatial lookup

1. 7F:000F / decoded 0x000F is a 16384-entry u16 coarse-sector table, indexed as (y>>6) * width + (x>>6).
2. Each u16 value selects one of 32 records at 7F:800F / decoded 0x800F by multiplying the value by 32.
3. Each 32-byte record is a 4x4 grid of u16 packed surface words, resolving the 64x64 sector to 16x16 world cells.
4. For normal packed words, 81:8C11..8C2C derives a C000 slot; that slot identifies both the C000 behavior/orientation byte and the paired 32-byte A000 surface block.

The earlier 33 x 1024 plane-major hypothesis is rejected. The 0x8000 boundary is a two-level indirection split.

## Materialized resource ownership

| ID | size | A000 range | C000 range |
|---:|---:|---|---|
| 01 | 0x0080 | 0..31 | 0..0 |
| 02 | 0x0080 | 32..63 | 1..1 |
| 14 | 0x0200 | 64..191 | 2..5 |
| 24 | 0x0480 | 192..479 | 6..14 |
| 16 | 0x0200 | 480..607 | 15..18 |
| 18 | 0x0080 | 608..639 | 19..19 |

Resource 0x24 owns C000 slots 6..14; all nine are confirmed checkpoint/finish behavior code 0x14. Those slots occur in fine records [1, 2, 3, 16, 17, 18, 19, 20, 21, 22, 27, 29, 31] and in 31 coarse-sector placements.

## Query contract

Example: python3 tools/build_course_presentation_contract.py --query-rect 1088 768 1408 896

The JSON result returns every touched 16x16 cell with coarse sector, fine-record ID, packed surface word, C000 slot, paired A000 range, and owning tail resource.

## Stop boundary

- sufficient on Dragster: world extent and camera masks
- sufficient on Dragster: 64x64 coarse sector to 32-byte fine-record placement
- sufficient on Dragster: 16x16 fine cell to packed surface word
- sufficient on Dragster: normal packed word to C000 slot, A000 block, and owning tail resource
- sufficient on Dragster: checkpoint-finish resource cells located in world sectors
- sufficient on Dragster: deterministic ROM-derived region query
- deliberately open: packed control-bit semantics beyond the resource-selection path
- deliberately open: gameplay activation and liveness
- deliberately open: graphics extraction or replacement art
- deliberately open: editor-complete names for every packed field

Check the same two-level boundaries, dimension transform, and packed-word ownership invariant on a small cross-course sample before any 45-course census.
