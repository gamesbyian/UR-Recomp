This is a **nonshipping, reversible 2026 blockout visual study**, using the one already-published, source-SHA-gated five-parent/sixteen-material GLB. Experimental [#3145](https://github.com/gamesbyian/UR-Recomp/pull/3145) has already been fully verified against the **actual** OpenSCAD-exported 2026 GLB, 48 source-authenticated original Mesen blue/red images, their 23 genuine consecutive original changes and one fixed provisional 7:6 camera. The real-GLB/Chromium [run #41979989112](https://github.com/gamesbyian/UR-Recomp/actions/runs/41979989112) and [artifact #13393994215](https://github.com/gamesbyian/UR-Recomp/actions/runs/41979989112/artifacts/13393994215) showed all **16 earlier controls deeply unchanged**. Longitudinal ×1.10 produced original upper-change IoU for blue **.20895522** versus prior upright-saddle **.17910448**, and for red **.11688312** versus **.06944444** under the existing opposite best wheel controls. Blue static silhouette IoU declined modestly **.56870778→.56455669**, while red source upper false positives increased **53→58**. This is an informative *mixed* source-space research outcome, not unique historical 1994 saddle geometry or a newly approved default.
