The [genuine completed 205-member Dragster→Zoo archive](https://github.com/gamesbyian/UR-Recomp/actions/runs/39180473171) contains 311 actual reference/native controller rows. Its previous evidence established original/native agreement but did not independently establish that those rows were **the actual 2014 SMV P1 controller segments**. Two matching but changed guest input files might otherwise pass pairwise verification.

This minimal implementation reuses existing [canonical 2014 source input attestation](../tools/qa01_event_historical_source_attestation.py), [supplied-input route auditing](../tools/qa01_event_route_artifact_audit.py) and the same genuine [Dragster workflow](../.github/workflows/qa01-dragster-zoo-2014.yml). It rejects a changed SMV digest, movie controller metadata/ROM CRC, source event identity, absent or ambiguous original P1 controller window, any missing/reordered/changed original or native event tuple, wrong independently observed native guest offset or changed original replay script. In particular, a *forged matching pair* of reference/native button files is now compared against the actual 2014 movie and must fail.

The original Bowl-specific source verification path remains byte-for-byte unchanged, while the historically anchored source path is usable for Dragster and the already supported general campaign cases. The manual Dragster workflow runs the actual original/native case once, reopens its previously verified real 14 paired full-memory images, then requires the **independent source P1 input receipt** before executing/qualifying the guest-level cold recovery. The original tiny `dragster-source-input-identity.json` becomes part of the same existing original Actions case archive, with exact producer SHA. No new runner/factory, native emulator, source mask, input shift, temporary course bypass or new gameplay comparator was added.

**Real-execution gate:** until a new exact-head Dragster workflow finishes and its original artifact contains the authenticated source input receipt, this is *infrastructure only*. Earlier 69/199/205-member archived cases do not retroactively acquire stronger input evidence. Even a valid receipt certifies only the actual *supplied P1 input files*.
