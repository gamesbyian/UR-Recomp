## Scope and authority

The five canonical Modern root destinations remain **Play, Practice, Multiplayer, Records, Options** in their established order. This lane owns the **opened destination compositions** and the stock-backed profile child surfaces in `native/product/modern_native_destination_presenter.hpp`. Multiplayer opens the two-seat catalog-backed join or the explicit unrecorded-stock-2P consent. Records reads canonical 1P runs/2P matches; Options reads/apply only the existing real host settings. Racer setup uses actual preset/catalog state and next-boot commit semantics.

Integration and a packaged Windows screenshot on the **same merged head** are required before a widescreen-native acceptance claim.
- Paused Options reuses the exact same product-owned setting values and painter without overprinting the legacy modal. The host's frozen-guest draw entrypoint now calls `render_modern_native_pause_destination` (1x/2x), preserving the same input and save model. Records is explicitly read-only; no new replay or save action. The warning displays lack of history for unbound 2P. Racer switching is marked for next boot, never immediate. Practice exposes original unlocked-tour count and source-route launch status, not speculative courses.
- The real native adapter draws the shared root shell with its legacy child panels hidden in a local presentation copy, then paints the new child surface using the unchanged authoritative view. This avoids ghosting the translucent legacy text underneath. It never edits the shared renderer file, root cursor, menu model or guest pixel data outside the overlay. This is the integration seam for the title and shared visual-language agents. Avoid separately modifying the native root presenter for these six child views; coordinate on `ModernRootOverlayView`/palette changes if a shared component API evolves.
