# ART-4K original pose-family corpus: bounded hosted research

**Goal:** bypass the manual HP source file-picker for the next real original 3D reconstruction experiment. The canonical USA ROM is already present at the exact repository path used by existing hosted source QA. The registered deterministic original-sprite exporter already exists, as does its shape-disjoint source-family freezer. This workflow reuses those two tools: no new exporter, rig, viewer, game code, timer or HP workload.

## Owner's data-discoverability direction

This noncommercial research project's owner explicitly accepts original ROM/sprite research material being discoverable. The hosted Actions artifact includes actual source-registered 64x64 original racer PNGs; it does **not** include the 2 MiB original ROM binary. Acceptance of visibility does not grant redistribution rights or override external platform rules.

## Operation and qualification

Workflow: .github/workflows/art4k-original-source-family-corpus.yml

Runs only for PRs changing this dedicated workflow/test, or manually via workflow_dispatch. No recurring schedule, default push dispatch, new runner label or credential write scope. A single hosted Ubuntu job verifies the exact canonical source ROM byte count and SHA-256 (859ec99fdc25dd9b239d9085bf656e4f49c93a32faa5bb248da83efd68ebd478), invokes the already existing Python stdlib exporter on **all registered source windows**, and revalidates all published originals through the already existing source-family split freezer.

The uploaded short-lived Actions ZIP has a verified source-corpus.json completion receipt, SHA-named deduplicated authentic source PNGs, conservative all-diagnostic roles JSON, and the independently verified overlapping-window binary-silhouette component report. Every window remains diagnostic until a research worker *explicitly* freezes fit/withheld-candidate roles from this actual source receipt. A distinct binary mask shared by multiple windows is never allowed in both fit and held-out sets.

On a failed ROM hash, missing window, compositor error, missing source PNG, bad shape grouping or incomplete receipt, the producer exits without uploading a success artifact. A successful run proves exact registered original source raster bytes, **not** a true 1994 3D camera or source pose/rig correspondence.
