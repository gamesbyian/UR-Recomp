## Independent recovery comparison

- Both the unjournaled legacy mode and prewrite-intent mode execute the source-backed guest at frame **1952**, complete the real original 8,192-byte raw SRAM write, then terminate with injected Windows Exit(86) before typed publication. Independent comparison shows **exactly the same 28 changed SRAM bytes** in both cases (old hash bd9571f85e..., new hash 2f3009bb...). The original typed profile, selector and catalog are byte-identical at the crash.
- Without an intent, a new real Windows process **refuses** divergence and leaves the typed generation 1 unchanged. Separate same-binary logs show the explicit one-shot guest-raw choice and fresh native guest restart. There was no automatic unauthorized promotion.
- With the intent, a fresh real native process reconciles the original typed generation **1 → 2**. The resulting typed stock SRAM, independently decoded from the complete typed file, exactly matches the 8,192-byte guest-written raw data; **30 typed file bytes** changed. The selector and roster catalog remain byte-identical.
- The crash-time **33,094-byte versioned intent** has SHA256 **5e32c9dfcef38c0dc75db4a7696041f1381f7e93da4f7f68bf796a173d98435e**. Independent length-frame decoding proves it embeds the **complete exact old and new typed files**, not arbitrary checksum assertions. The original intent and immutable recovered receipt are byte-identical, their separately archived length/SHA256 flags agree, and the pending-intent retirement is recorded.
- A separate second genuine Windows cold-boot log shows the previously recovered guest booting without another RECOVERY_RECONCILED. Product-owned test checks report the four canonical files unchanged across that second run. **Independent QA only has the first three-stage bytes and two log transcripts**, not a separately retained four-file post-second-boot snapshot. Do not overstate that boundary.
- The healthy-alternate Win32 producer also explicitly selects a valid second profile and boots it without altering the damaged source, but that source damage was **fixture-injected**.
