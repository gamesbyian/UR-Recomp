## Proposed post

I'm seeking a few technically curious people willing to **donate some agent run-time and supervise it lightly** on real, bounded tasks in an existing Uniracers / Unirally reconstruction project.

**Project at a glance:** [Uniracers MODERN recruitment and contact](https://gamesbyian.github.io/UR-Recomp/contributors/). The unofficial, unpaid project has substantial engineering progress and experimental Windows test builds; every volunteer role offers email and optional GitHub contact without requiring an account.

The [public repository](https://github.com/gamesbyian/UR-Recomp) has [agent instructions](https://github.com/gamesbyian/UR-Recomp/blob/main/AGENTS.md), a [ranked shared work queue](https://github.com/gamesbyian/UR-Recomp/blob/main/docs/WORK-QUEUE.md) and independent source-bound QA. Five existing scheduled agents are generalists. A volunteer could perform one code review, test improvement, reproducible experiment, or small feature PR, on their own agent account, without giving the project any API credentials.

The particularly interesting bit is agent governance: there are strict evidence boundaries and human-independent release qualification. Green generated tests don't automatically award release acceptance. This is a real, evolving codebase rather than a toy one-shot prompt.

Completely **unpaid and optional**, no minimum time, and code/CI privileges are not automatically granted. If you want to try one scoped contribution or independently inspect agent-produced work, say what tools and oversight you're comfortable using.

I'm also actively interested in coordinating with other Uniracers / Unirally remakes, recompilations, preservation and art projects. I'm familiar with the [Baldosa](https://github.com/baldosa/uniracers-recomp) and [malmazuke](https://github.com/malmazuke/unirally-reconstruction) projects, and would welcome contact from other teams to share findings or avoid duplicating work. I'm not claiming any current partnership with them.

To help, use the [recruitment website](https://gamesbyian.github.io/UR-Recomp/contributors/) to contact the project by email or optional GitHub issue, or reply here where permitted. No GitHub account is necessary.
