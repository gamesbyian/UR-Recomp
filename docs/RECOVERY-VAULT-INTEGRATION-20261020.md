## Rules for subsequent independent integration

- Recover the **latest applicable** file for each target and verify the Git blob preimage and archived patch SHA. Never stack older overlapping graphics composites over newer ones.
- Qualify standalone read-only prototype/test additions independently. Keep synthetic signed/checkpoint/parser evidence separate from authentic original/native observations.
- Demand exact PR-head tooling, repository hygiene and any relevant native Windows workflow; if behind `main`, independently qualify the merge epoch.
- Keep signed/authentic original/native RTS operands, source-epoch PPU final pixels, actual Windows two controllers/audio/4K/NTFS recovery and human character-art likeness as **unperformed independent gates** unless new direct evidence exists.
- Keep large raw artifact archives and reproduced source ZIPs in Drive at their immutable URL/SHA, not silently import them into shipped product or interpret them as source code approvals.
