# RF084: native actual paced byte/word sound-transfer writer return probe

**Source-only instrumentation, unexecuted until an independently authenticated original/native case.** No timing fix, no reconstructed gameplay, zero USA event/Windows gate credit.

The genuine original Snes9x [RF083 trace](QA01-RF083-ZOO-SOUND-DP-FIRST-WRITER.md) identified **82:80E0 E6** as the original $0069 transfer-counter increment on 1,482 raw byte changes, and **82:8154 E6** as the original $0063 pointer increment on 1,481 low-byte changes and six high-byte carries. A separate static source inspection of `gamesbyian/uniracers-recomp@10b864b9d14a7b7416dd909eb7b054c88faef101` tracked `src/gen/bank82_part00_v2.c` shows the native `L_80E0_M1X0` block performs `cpu_read8_paced` followed by `cpu_write8_paced` at `D+$0069`, while `Snd_IncDataPtr_FastRom_M1X0` with `REP` before 82:8154 performs `cpu_read16_paced` and `cpu_write16_paced` at `D+$0063`. This is **static emitted-source correspondence**, not a witnessed native runtime call.

RF084 is an opt-in **post-regeneration** research patch applied with `python3 tools/qa01_rf084_native_sound_dp_committed_writer.py --root baldosa` on the disposable exact pinned game source after the existing RF-015+RF-017 regeneration and *before* compiling native. It only modifies `src/gen/bank82_part00_v2.c`. It checks the exact original function+M1X0 block label and one existing paced 8-bit/16-bit writer in each; it refuses source drift, duplicates, missing mode variant or repeated staging. At runtime, `UR_QA01_RF084_NATIVE_SOUND_DP=1` records actual generated call path **after** each real paced writer has returned, its original raw bytes captured before that writer, full native D, effective address, written value, direct raw post-write contents, guest-site label, host frame and native master clock. A finite recorder emits a `TRUNCATED` marker after 10,000 records. Code performs **no new guest-bus helper calls, writes, clock charges or controller changes**. This observer only claims `native generated writer returned`, not that the same original opcode was fetched at a semantically aligned instant or that a first downstream SPC consumer read the value.
