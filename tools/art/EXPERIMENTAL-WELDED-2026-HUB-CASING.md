# One connected manifold dark hub: a structural 2026 source-model experiment

**Purpose:** the existing unapproved #3124 2026 dark near-side physical casing hypothesis is two overlapping closed volumes in the original source dark material. This is fine for flat render tests, but poor for an articulated source model, meshing and any eventual game quality. This single alternative replaces the two overlapping solids with **one connected, watertight, coherently oriented and nondegenerate genus-zero 2026 mesh**, preserving the eight outer chamfered corners and source-axis scale.

The immutable original source `rim_and_hub__material_4` sleeve has 100 vertices, 196 triangles, a 50-section circular radius ~0.086 source 2026 units and Y extent -0.21…+0.21. Original authored 2026 cover has eight-bevel X span -0.30…+0.22, Z -0.37…+0.27, Y +0.18…+0.38. The new mesh samples the original 50 sleeve angles **plus all eight actual cover corner rays** (58 angles), reconstructs four ordered rings: sleeve rear -0.21, sleeve near join +0.18, polygon rear +0.18, polygon front +0.38; bridges sleeve and casing with an actual planar annular face, caps each exposed end once at a true interior vertex, and removes the overlapping hidden inner sleeve face. This yields **234 vertices, 464 nonzero-area triangles, Euler characteristic 2, one closed topologically connected shell, outward normals and signed volume ~0.07496005181 2026³**. Original overlapped material had numerical volume ~0.07565313 because its overlapping physical regions were counted twice. A ray/segment intersection with source-authored polygon, rather than guessed corners, conserves all eight original casing boundary vertices.

The **existing** five-part/16-material GLB material identity, original model pose transforms, other 15 source meshes, source static sprites and printed 1994 references remain untouched. `temporary_welded_source_hub_casing(scene)` is an opt-in, reversible context manager that first requires the original source hub colours/vertex counts, original five-part graph and exact source radius. It verifies actual `trimesh` watertight/winding/Euler and signed volume in memory, then restores the source arrays and all other materials/rig transforms on exit or error. A pure Python topology check counts every triangle edge with opposite winding twice and confirms one connected shell by graph traversal, independent of a renderer.

**Evidence limits:** This is a *2026 physical topology repair* of an invented casing silhouette, motivated only by one partly occluded **1994 printed 2D patch**. The original 1994 production source mesh, geometry, material assignment, camera, axle joint and view depth are all unknown. The 2026 candidate is still owner-rejected for shipping. It is not a recovered original 1994 physical hub, art approval, new canonical rig, renderer or release asset. Shape/temporal score improvements must be verified under the existing unchanged two-player original Mesen24 model/scorer before any further claim. The welded exterior is geometrically aligned to the old overlapping candidate; expected image silhouette similarity is a hypothesis to independently test, not an asserted original 1994 observation.
