## What actually earns progress

A **completed player journey** with runnable source-bound evidence, a **reproduced bug fixed and tested on its genuine integration route**, a **qualified PR merge** with the dependency closed, or a **new accepted independent gate/event**. Partial source improvements still count as implementation work, but not automatically as release clearance. A new issue, renamed task, another isolated synthetic test, ZIP moved between Vault folders, or unqualified green workflow is not product acceptance.

**Evidence economy:** Before doing expensive work, reuse current-source checks and the cheapest available discriminator. Respect the shared 20-runner practical budget and no-CI-babysitting rule; advance another truly independent job while waiting. Select the next job only after reading the live board and latest PR/issue state. A WIP branch is not a reservation without real concurrent writes.

**Risk direction:** The owner accepts the risks of ROM and ROM-derived evidence being discoverable publicly and values unimpeded, reproducible R&D. Do not invent secrecy, redaction or private-path requirements solely from discoverability. This does not claim a redistribution license, override an explicit platform/legal restriction, waive a denied operation or justify weakening real credential, save-data or CI integrity controls. See [the owner policy](OWNER-ROM-RESEARCH-RISK-PRIORITY.md).
