# Research-only original-2026 wheel-support sculpt in the Pages model viewer

One existing SHA-authenticated five-parent/16-material **2026** source GLB is the only model admitted. The **Research wheel spoke volume** control allows original source eight rods or one temporary wide-blade candidate. This is the identical bounded eight-spoke, original 11° + i×45° angular width transform authored and independently volume-verified in the nonshipping #3172 experimental branch. It moves only `rim_and_hub__material_2`, retaining all original eight spokes, wheel radial positions and Y depth; material colours, hub, tire, frame, saddle, pedals and model graph remain untouched.

The original Nintendo/DMA USA 1994 manual p15 shows broad metallic supports from a pronounced underside oblique view. Neither its original 3D production part geometry nor a calibrated camera is recovered. Width factor 2 is a **single frozen 2026 experimental model preview**, not an inferred historical 1994 dimension or automatically approved 4K game art. Previous source 48-frame fork/crown six-objective metrics are unrelated and must not be interpreted as spoke scores. Original original-game 24-tick 64px sprite rail never changes.

This selector is enabled only with the published source-owned GLB after the existing real source SHA and rig/material gate, the exact source spoke mesh of 1,788 vertices and its named existing parent. It does not work with a local user upload, a fake browser test GLB or a different model. A candidate replaces its geometry with a temporary clone, recomputes normals/bounds and immediately restores and disposes the clone when returning to original or changing model. The 412px full real-GLB browser test must prove original→broad→original pixels differ then restore **exactly** under one frozen camera. The 320/412/1440 browser checks must also maintain >=44px source control targets, original Mesen sprite independence and unavailability for unsupported models.

Users can compare the original and wider wheel supports with the existing **Print hub** camera preset while inspecting authenticated manual image crops via the local-only annotation link. The print image is independent of the 2026 GLB scene and is not embedded as an editable 3D object. No alternate GLB is exported, game renderer changed, owner likeness signoff granted, or Windows release/ART gate awarded.
