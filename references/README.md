# External reference corpus

This directory records public Uniracers / Unirally material that may help reverse engineering, validation, reimplementation, graphics study, or historical reconstruction.

## Rules

1. Every item gets a source URL, retrieval date, and rights/licensing note in `catalog.yml`.
2. Pin GitHub sources to a commit where practical.
3. Copy third-party files into this repository only when their licensing/status makes that reasonably clear. Otherwise, preserve metadata, links, and our own derived notes instead of silently treating the material as project-owned.
4. Keep copied material under `references/imported/`; keep our summaries and technical observations under `references/notes/`.
5. External claims remain leads until reproduced against the project's supported ROM. Confirmed local findings belong in `docs/RESEARCH-LEDGER.md`.
6. Do not import third-party ROM images. The project's own ROM baseline is handled separately.

The corpus is deliberately provenance-first. A reference that later disappears should still leave enough information here to identify what it was and why it mattered.
