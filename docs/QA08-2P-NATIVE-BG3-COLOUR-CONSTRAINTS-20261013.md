## Source-observed PPU registers and exact native pixels

The original native PPU completed field has only **one colour register write**: `CGWSEL=$2130=0x02` at beam **V=239**, in blanking before visible row0. Genuine *completed and recording* baseline fields are both CGADSUB `0x04`, CGWSEL `0x02` and fixed RGB15 `0x0260` = RGB5 **(0,19,0)**. The **CPU-side raster journal alone** reconstructs those saved values at every visible native tag 0–223; this does **not** prove the live fixed-colour value after render-time HDMA. A subsequent original native PPU per-pixel probe [#1433](https://github.com/gamesbyian/UR-Recomp/pull/1433) directly observed **live fixed15=0x000F at upper y50** and **live fixed15=0x0260 at lower y162**. The latter equals the field baseline; the former differs. The pinned [beam-to-output crosswalk](QA08-PPU-RENDER-LINE-CROSSWALK-20261013.md) maps native tag N to original framebuffer row N. With these registers the pinned PPU allows colour math on **BG3**, not OBJ (CGADSUB bit2 set, OBJ bit4 clear); CGWSEL bit1 selects a subscreen operand when present.

The older independently accepted original/native PPU counterfactuals deleted only **upper front OAM slot98** and **lower front OAM slot96**, in independent native processes with matching guest CRCs. No such deletion is permitted in normal Original or Remastered shipping.

The six new direct PPU pixel records, generated by pinned native job `38498698636`, settle the two selected source pixels: **BG3** is the main red13 text operand and native **OBJ** is the subscreen grey6 operand at upper (133,50) and lower (133,162). The upper OBJ has native layer-class tag **6**, the lower class **4**. Removing the front OBJ empties the subscreen pixel in the affected viewport and falls back to that scanline's **live fixed colour**, red15 above and green19 below. In both stock positions, (13,0,0)+(6,6,6)=(19,6,6) exactly. This is **observed source composition only at these two coordinates**, not yet all 26, and not physical SNES hardware acceptance. It validates the authentic journal frame, complete guest-CRC count, both 224-line CPU-journal-only reconstructed colour-register states (not live HDMA-colour states), all **five raw 342x224 P7 payload SHA256** digests (unmodified Original, two independent isolated OBJ planes, two independent source-deletion Original frames), and all **26 individual RGB triplets** in the previously independently accepted front-text causal JSON.
