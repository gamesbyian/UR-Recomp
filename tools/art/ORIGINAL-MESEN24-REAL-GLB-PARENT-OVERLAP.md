# Actual original upper-event pixels against the five 2026 GLB parents

This experiment extends the source-verified neutral geometry census in [#3119](https://github.com/gamesbyian/UR-Recomp/pull/3119) to **genuine original PPU 2P events**. It joins the previously SHA-verified 24-tick original Mesen archive and exact ROM phase/orientation IDs to the same current-success 2026 five-parent/16-material GLB exported in the existing Windows Visual Atlas job.

Only original blue OAM96 tick **1603** (source orientation 60, phase 8) and red OAM97 tick **1606** (orientation 58, phase 15) are scored. These are the already examined upper-band event destinations, **not independent new holdouts**. The original source-local sprites are not silently horizontally reflected into the completed-screen convention. One original tick1601 alpha registration per player, one unchanged provisional 7:6 camera, and one neutral model anchor apply to all five 2026 parents together. The tested 2026 pose arms are static, previously fixed **absolute source index wheel-axle root**, and previously fixed **absolute source index historical mid-body root**. The original orientation index is not a measured 1994 physical angle. No new geometry or camera/pose fit.

Each existing 2026 actual GLB part is rendered as an independent projected 256px triangle silhouette, retaining original parent transforms. The five projected 256px masks **must OR-union exactly** to the repository's established whole-GLB mask; the translated 64px parent masks must likewise exactly reconstruct the original comparison's complete model mask. Counts in fixed image bands y0–14,15–26,27–63 distinguish original-only missing pixels, model-only pixels, source/model intersections, each 2026 parent's overlap and support **exclusive to that 2026 parent**. Overlapping parts are non-additive; this is a geometry/support diagnostic, **not a claim that a given original 1994 sprite pixel belonged to a saddle or other 3D part**.

A successful outcome narrows *which authored 2026 3D part* requires further paired-pose/camera/shape research. Neither a one-frame IoU gain nor source-part coincidence justifies altering the canonical rig or reversing the owner's character-likeness veto. Novel-view/high-resolution evidence is still missing.

Run using the same staged original ZIP, source pose+axis reports, current-success 2026 model and camera as #3116, without new emulator or independent GLB exporter. Full CLI and exact source/candidate hashes are recorded in the report. Exact-head tooling, real GLB export and Chromium qualification are required before merging.
