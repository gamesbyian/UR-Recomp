The existing mobile **Mark original printed 2D landmarks locally** Pages tool adds an optional collapsible **Trace a partly visible original printed surface** section. Load the exact original four PNGs and `source-crops.json` through the on-device file picker; the browser verifies all four provided PNG SHA-256 values. Select a figure, give the partial patch a short lowercase slug and appearance/occlusion descriptions, press **Trace surface taps**, tap the actual visible polygon points (or enter source X/Y values in the existing numeric control), then **Save 2D polygon**. The image overlays the polygon; a mistaken/unfinished trace can be cancelled or cleared before export.
