# Real original Mesen24 vs real 2026 GLB: six-objective Pareto audit

**Goal:** make the rapidly accumulating 3D saddle, wheel, stem and frame experiments comparable without quietly choosing different "winning" parameters for blue and red. This is a deterministic post-processing step, not a new source dataset, optimizer, 3D asset, emulator, workflow or acceptance gate.

The actual source has two original racers, each observed at **24 consecutive original Mesen PPU images**, including **23 actual changing-pixel edges**. The 2026 GLB candidate's shape overlap is measured two different ways: all real chronological frames and one vote per unique original 64px shape (to avoid repeating identical images as artificial evidence). Temporal overlap is the pooled original 23-edge XOR alpha IoU. Each *candidate* therefore has **six independently maximized measures**, one each for chronological static/unique static/temporal motion for blue and red. The old original source 2D rotation reference remains visible but **is excluded from the population of actual 2026 GLB models**.

The pure-standard-library `tools/art/rank_real_glb_mesen24_pareto.py` rejects missing source players, absent source ticks, mismatched named arms, unverified original ROM/Mesen24/source camera/2026 SCAD SHAs, art approval claims, fabricated edge IoU, missing upper/middle/lower source band counts or non-conserved pixel events. It ranks *only* real GLB arm names which are in both source roles, and reports strict mathematical Pareto dominance: model A dominates B only when A scores **at least as well on all six source objectives, and better on at least one**. Equal-score alternatives and genuinely mixed blue/red or shape/motion tradeoffs remain nondominated. No weights, aggregate scalar, per-role selection, fitted degree, camera retune, mesh change, dynamic source ground truth or "best original 1994 model" are introduced.

**Usage on the existing exact source-owned Windows GLB evidence:**

```sh
python3 -m unittest tests.unit.test_rank_real_glb_mesen24_pareto
python3 -m tools.art.rank_real_glb_mesen24_pareto \
  --real-glb-source-report /verified-run/real-model-evidence/original-all24-saddle-only-generalization.json \
  --out /new/real-glb-two-player-pareto.json
```

Do **not** commit the enormous actual GHA artifact or schedule an extra Windows render; feed the report generated by the existing Windows Visual Atlas source-owned real GLB stage into this analysis when selecting the next single geometry experiment. Each SHA-verified exact-head real report can produce a standalone immutable and non-overwriting Pareto receipt, independently audited against the historical controls. The six-objective Pareto frontier is a *candidate short list for human visual review*, not an optimized 1994 mesh or proof of likeness; results remain retrospective and owner character-art veto and Windows ART/release gates continue unchanged.

**Next decisions:** inspect saddle longitudinal span ±10% alongside independent saddle stem slide ±0.12 and frame axial stretch ±4% on the same authentic source, preserving each experiment's qualification.
