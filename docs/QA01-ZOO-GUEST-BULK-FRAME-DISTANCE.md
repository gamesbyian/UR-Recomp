# QA-01: Zoom Zoo original/native full guest memory phase-distance census

Independent original Snes9x and pinned Baldosa guest dumps from [CI run 38018081196](https://github.com/gamesbyian/UR-Recomp/actions/runs/38018081196), artifact `11656564258`, have been compared in scene-relative frames **+5155 through +5173**. [The raw byte-distance report](../analysis/data/zoo-original-native-bulk-frame-distance-20261009.json) retains the archive fingerprint, the full 128 KiB WRAM + 64 KiB VRAM + 512 B CGRAM dimensional contract and every candidate's best matching source-relative offset. The source-independent analysis command is `python3 tools/analyze_zoo_bulk_frame_distance.py --artifact <existing-actions-artifact.zip> --out <local-report.json>`; it never boots either runtime or rewrites a ROM, SRAM, guest state or controller stream.

The key existing observation **repeats exactly**: native +5156 matches original +5157 byte-for-byte across **all 197,120 memory bytes**. The original/native fixed same-relative +5155 WRAM also matches exactly, although the PPU VRAM snapshots still differ by 29 bytes. From native +5157 to +5163, original +1 is consistently closest by total memory differences, but not identical. Around +5168 through +5173, the nearest *whole-memory byte pattern* is often original +2, partly because the post-result contact cleanup and animation state are sampled at different phases.

**That is not evidence that Baldosa's guest suddenly gained another frame.** A byte-distance minimum is not a time-synchronized CPU instruction, NMI/VBlank entry, PPU scanline, game loop iteration or controller latch. Postresult VRAM/CGRAM values often remain constant across multiple frames, and a handful of residue bytes can select an apparent best lag. The independent original opcode `83:988A` and native `Sram_RestoreDirectPage_FastRom_M1X0` writer chronology in [the source-owner witness](../analysis/data/zoo-original-native-sram-restore-source-owner-20261009.json) remains the appropriate causal research seam. Preserve **0/45 USA complete-event acceptance**, with no input phase shift, guest timing patch, physics change or fabricated acceptance.
