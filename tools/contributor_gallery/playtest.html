Windows x64 · Human testing

Give the racer a spin.

Experimental, playable Windows builds already exist. Human testing helps discover what automated tests and emulator comparisons miss.

These are work-in-progress test candidates, not a finished public release. You'll receive a specific verified ROM-free package and its instructions when one is available for your session.

Want to playtest?

Send a note about your Windows computer, controller (if any), and how familiar you are with Uniracers / Unirally. An original-game expert isn't required.

Email about playtesting ↗Contribute on GitHub ↗

Email and GitHub are equally welcome. You don't need a GitHub account to help.

What a session looks like

  1. Get the current qualified Windows test candidate, version/provenance and setup notes.
  2. Play through a few targeted routes, or explore and report what feels wrong.
  3. Send back a short reproduction, screenshot or observation through email or the public test form.

Never share a copyrighted ROM or private data in a public GitHub issue. No purchase or payment is required.
