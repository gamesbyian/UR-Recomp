The pinned native SNESRecomp `dma_doHdma` and `dma_primeHdmaFirstLine` implement mode-1 transfers using `bAdrOffsets[1]={0,1,0,1}` and `transferLength[1]=2`. **The already accepted second destination is $2132**, so the first destination must be **$2131 CGADSUB**, *not* $2133 SETINI. The original Snes9x guest writer bytes previously investigated at `$7E:2087/208A/208D/2090/2093` are **not** source-proven companion $2133 register writes; they are adjacent data/descriptor state whose actual use requires separate proof.
