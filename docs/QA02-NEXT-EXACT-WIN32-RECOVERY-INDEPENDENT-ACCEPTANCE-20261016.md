## Fix-producer-to-independent-QA handshake

1. **Implementation owner** reports a focused PR and merge commit solving [#1214](https://github.com/gamesbyian/UR-Recomp/issues/1214), defining the canonical protocol and all allowed recovery choices. No second save authority, silent raw trust, implicit victory/medal, forced profile reset or replacement of a verified typed or raw snapshot. Preserve exact before-state bytes and documented rollback/repair.
2. **QA nominates a new, explicit candidate**, never relabeling the prior `11501a15` source/ZIP. Use the existing manual Windows candidate route **once** on a settled merged `main`, hash actual tested `main`, ROM-free ZIP, PE, original ZIP wrapper and test route, and recheck source/ZIP/EXE identity from independently downloaded artifacts. Record how/why the new package supersedes the negative source for further tests; the original negative identity remains as history.
3. **Independent QA** runs one minimal, bounded matrix below on actual new ZIP/PE and separated disposable data roots, consumes the original six archives as comparison inputs, hashes snapshots before/after each cut, and obtains the first failed log/step. Explicitly distinguish test injection, subprocess kill, ACL, genuine disk-full and physical power cut. Existing managed Windows runners can test the first four; actual power loss/physical controllers require a named human witness.
4. **Gate owner** alone determines any ledger `witnesses`, `candidate_commit`, status or release decision. A green product unit test or rehashed ZIP alone earns **zero** of the 12 QA gates and **zero** of 45 original/native complete event approvals.
