# Regional names and search vocabulary

The project should search under more than the North American retail title.

## Confirmed retail / ROM identities

- **Uniracers** — North American retail title; internal title `UNIRACERS`.
- **Unirally** — European/PAL retail title; internal title `UNIRALLY`.
- Australian PAL cartridges also use the Unirally/PAL family.
- A released European prototype is labelled `UNIRALLY PAL`.

Useful historical filenames include:

- `Uniracers (USA).sfc`
- `Uniracers (U) [!]`
- `Unirally (Europe).sfc`
- `Unirally (E) [!]`

A Japanese fan/database transliteration `ユニレーサーズ` appears in ROM databases even though the game was not commercially released in Japan. That makes it worth including in Japanese-language web searches, alongside `ユニラリー` and generic Japanese SNES reverse-engineering terms.

## Search-language vocabulary

Future harvests should combine both game names with terms such as:

- English: hack, ROM hack, level editor, map, sprites, rip, disassembly, reverse engineering, prototype, beta, save, SRAM, cheat, Game Genie, patch
- German: ROM-Hack, Level-Editor, Karte, Sprites, Disassemblierung
- French: hack ROM, éditeur de niveaux, carte, sprites, désassemblage
- Spanish: hack ROM, editor de niveles, mapa, sprites, desensamblado
- Italian: hack ROM, editor livelli, mappa, sprite, disassemblaggio
- Portuguese: hack de ROM, editor de fases, mapa, sprites, desmontagem
- Russian: ром-хак, редактор уровней, карта, спрайты, дизассемблирование
- Japanese: 改造, ROMハック, レベルエディタ, マップ, スプライト, 逆アセンブル

Searches should also include developer/tool terms discovered from primary sources: DMA Design, Mike Dailly, Malcolm/Scott Maxwell, Andrew Innes, Robbie Graham, Martin Good, Rob Northen Compression, RNC, SNasm, and A0 plotter.
