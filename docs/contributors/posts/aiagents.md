## Proposed post

I'm running an unofficial Uniracers / Unirally reconstruction effort using a shared pool of supervised coding agents, and I'd love to meet people interested in **contributing their own limited agent-hours or independent reviews**.

**Project at a glance:** [Uniracers MODERN recruitment and contact](https://gamesbyian.github.io/UR-Recomp/contributors/). The unofficial, unpaid project has substantial engineering progress and experimental Windows test builds; every volunteer role offers email and optional GitHub contact without requiring an account.

The [actual code/research repo](https://github.com/gamesbyian/UR-Recomp), [AGENTS.md](https://github.com/gamesbyian/UR-Recomp/blob/main/AGENTS.md) and [engineering queue](https://github.com/gamesbyian/UR-Recomp/blob/main/docs/WORK-QUEUE.md) provide real work and explicit evidence rules. The point is not prompting a bot to produce a hundred unreviewed PRs: the work must remain source-bound, tested, reviewable, and compatible with other agents. Useful contributions include a bounded source experiment, a regression test, an independent verification, or a small code change.

No payment, minimum commitment or access to your API account is expected. This is an **unpaid volunteer collaboration** on an unfinished unofficial game.

I'm also actively interested in coordinating with any other Uniracers / Unirally projects. I already know the [Baldosa](https://github.com/baldosa/uniracers-recomp) and [malmazuke](https://github.com/malmazuke/unirally-reconstruction) efforts and would welcome shared findings, source comparisons and contact with additional teams. No partnership with those projects is implied.

To help, use the [recruitment website](https://gamesbyian.github.io/UR-Recomp/contributors/) to contact the project by email or optional GitHub issue, or reply here where permitted. No GitHub account is necessary.
