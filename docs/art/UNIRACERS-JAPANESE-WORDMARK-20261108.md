# Japanese Uniracers wordmark: ユニレーサーズ

**Status:** Original artistic proposal for owner review, not historical Japanese release artwork.  
**Date:** 2026-11-08.

The English title *Uniracers* is represented here with the user-supplied Japanese rendering **ユニレーサーズ** (*Yuni Rēsāzu*). This is a stylized katakana adaptation, not a claim that the original game shipped under this name in Japan.

Asset: [`assets/branding/uniracers-japanese-katakana-wordmark.svg`](../../assets/branding/uniracers-japanese-katakana-wordmark.svg)

The custom-drawn wordmark has seven symbols (ユ, ニ, レ, ー, サ, ー, ズ). Each uses editable cubic SVG centerlines with rounded terminals; the last character has two distinct dakuten strokes. The letters have deliberately curved bars, rounded turns and staggered vertical profiles to evoke the playful, unusual lettering of the existing North American and PAL artwork. No installed font, borrowed Japanese logo art, embedded raster or external resource is required to render the SVG.

**Brand treatment** matches the canonical English SVG values exactly: yellow `#ffea00`, black `#090409`, translated black outline `(+2,+2)` with 8-unit expansion beyond each source stroke weight, and a centered 2.4-unit black keyline. Unlike the English logos, the Japanese outlines are constructed from independently adjustable **stroke centerlines**, not one filled silhouette for each letter. This distinction is intentional: it makes stroke weights editable while the authoring process is exploratory.

The English Uniracers, Unirally and shared `unira` path definitions have not been altered. The user is the final judge of visual similarity, readability and layout. More expressive asymmetric weight could be developed later without changing the text. This work does not establish Japanese market release naming or any gameplay/release QA evidence.
