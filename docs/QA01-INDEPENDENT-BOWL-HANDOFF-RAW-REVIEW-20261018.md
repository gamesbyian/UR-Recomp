```bash
python3 tools/qa01_bowl_handoff_raw_archive_audit.py \
  --artifact-root /path/to/extracted/original-bowl-archive \
  --out /tmp/qa01-independent-bowl-archive-audit.json
```

The independent reviewer then verifies, without importing the event producer's comparator:

- Canonical USA course source/movie anchors, all original/native ROM/core/ELF/controller/source SRAM digest shapes, unrebased entry/result clocks, each real guest `script f=… dump` receipt and the exact source movie frame at every offset.
- **All** retained guest WRAM/SRAM lengths and hashes against the reported guest state; the actual menu/course/race bytes; Crawler Bowl course-index-2 rank-zero 764 value and full 150-record checksum in each true SRAM image.
- Recomputes the complete 131,072-byte pair difference, every differing 256-byte page, first 24 offset/value pairs, first/last address and original/native image hashes. Requires equality with **every** corresponding producer census object and all aggregate source/native comparison flags, with zero exclusions.
- Reconstructs the first actually *adjacent-observed* Switcher entry separately for movie, Snes9x and Baldosa, alongside actual independent host timestamps. Does not shift controller input or hide early/late transitions.

A **genuine observed difference** returns a verified bounded negative with exact first differing offset/count. A missing original raw file, short image, forged digest, altered host ack, misregistered movie input or contradicted producer count is INVALID evidence (nonzero exit), not a simulated gameplay regression.

**Scope remains carefully limited:** this verifier does **not** independently replay the 2014 source, validate the source's eight continuous Switcher active frames from a raw scan, authenticate the GitHub run SHA/artifact ZIP by itself, establish CPU/SPC/logic-tick fidelity or show durable Windows autosave. Read-only inspect the original run/ZIP and all source input identities separately. Even perfect raw equality yields `independent_complete_usa_event_adjudication: HOLD`, `accepted_event_credit: 0`; no write to the 45-course census or 12-gate release ledger.
