The pinned native runtime is `baldosa/snesrecomp@075fbe4c8e0d97b0013be541795c39cb644a9709` and the pinned game is `baldosa/uniracers-recomp@10b864b9d14a7b7416dd909eb7b054c88faef101`. Its `_emit_read` lines632–635 emits the actual operand consumption through `widths.read_fn(op.width)(cpu, bank, address)`, i.e. the existing native `cpu_read8`/16 helper, not necessarily `RomPtr` directly.
