## Proposed post

I'm working on an unofficial Windows recreation of the 1994 SNES game Uniracers / Unirally. The [project repository](https://github.com/gamesbyian/UR-Recomp) already has major original-game investigation and native frontend work, though an independently accepted full-game release is still some way off.

**Project at a glance:** [Uniracers MODERN recruitment and contact](https://gamesbyian.github.io/UR-Recomp/contributors/). This unofficial, unpaid project has substantial engineering progress and experimental Windows test builds; volunteers can use email or optional GitHub contact without an account.

I'd love to hear from people who spent a lot of time with the game: which tricks, control details, courses and little animation behaviours would make a recreation unmistakably authentic? I'm also building a list of people who would **opt in** to testing existing experimental Windows builds once a specific ROM-free package is verified for their session, and welcoming small voluntary art or technical contributions. Nobody is being promised a release date.

The work is unofficial and **unpaid**. Here's the [testing evidence protocol](https://github.com/gamesbyian/UR-Recomp/blob/main/docs/EXPERT-PLAYTEST-PROTOCOL.md) if you're interested.

I'm also actively interested in coordinating with any other Uniracers / Unirally projects. I already know the [Baldosa](https://github.com/baldosa/uniracers-recomp) and [malmazuke](https://github.com/malmazuke/unirally-reconstruction) efforts and would welcome shared findings, source comparisons and contact with additional teams. No partnership with those projects is implied.

To help, use the [recruitment website](https://gamesbyian.github.io/UR-Recomp/contributors/) and choose email or optional GitHub contact, or reply here where allowed. No GitHub account is necessary.
