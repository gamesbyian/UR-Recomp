## New deterministic QA guard, intentionally separate from product owners

`tools/qa_modern_visual_case_coverage.py` historically froze the five close-match candidate states, but the other **20** requirements could silently mutate while preserving their canonical ID: for example a P2-owned join could become a P1 acceptance target, a stale/disabled screen could become normal, Authentic could change to Modern, or the 4K virtual-output pixels could shrink. This branch pins all 20 remaining requirements' screen/mode/aspect/input/state/target pixels. It additionally freezes **all 25 review targets**, the canonical review authority, required-field schema and human checks, so that clipped typography, physical controller ownership, aspect/scale review and art approval cannot silently disappear while routes still look valid. New tamper tests cover P2, keyboard, disabled, locked, output-scale, earned Records, held-confirm, Authentic isolation and removed visual/hardware obligations. This changes **no renderer, guest, product router, host input bindings, artwork, workflow, or release ledger**. Legitimate future matrix revisions must consciously update the independent freeze alongside the new evidence scope.
