It accepts the five explicitly named auxiliary diagnostic logs but never uses their presence to award native settlement or release credit. A future product-owner change to evidence export must be deliberately reconciled by QA rather than silently accepting renamed files or private roots. Future **synthetic CI-only** run/match bytes should remain in their own explicitly reviewed bounded evidence artifact, never smuggled into this historical ROMless runtime-log wrapper.
