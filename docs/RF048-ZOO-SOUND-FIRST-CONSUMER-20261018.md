**Scope:** source-original USA Zoom Zoo sound DMA/CPU-SPC research only. This is a follow-up to RF035, RF037–RF042 and merged RF047. The existing original/native source-independent full-course acceptance denominator remains **0/45**. No production runtime change or independent release-ledger admission is requested.

## What was already proven

The exact RF037 V5 case [39010683041](https://github.com/gamesbyian/UR-Recomp/actions/runs/39010683041) matches all 45,645 original/native CPU port2/3 **payload values** after retaining only the three source-SPC-age-tied original write-order ambiguities. The two Zoo sound DP residual bytes persist exclusively at `7E:0063` at +5040 (`73` vs `74`) and +5045 (`B3` vs `B4`). Native actual CPU helper reads of 16-bit pointer `00:0063` are witnessed on native host6056→6057 (`C773→C774`) and 6061→6062 (`D0B3→D0B4`), scoped to `Snd_IncDataPtr_M1X0` then `Snd_UploadBlock_80D1_M1X0`. The first later host-frame read is a *real native consumed pointer*.

RF035 and RF037 source Snes9x actual `82:82F0 LDA [$63],Y` instruction captures were bounded by reporter truncation and did **not** log `Registers.D.W`, so their `Memory.RAM[0x63]` debug byte cannot be called the original indexed consumer's source pointer. Original `ICPU.Frame` is not automatically native host frame, and all sampled whole-WRAM source/guest pairs are still unmasked (78 checked, 51 exact, 92 differing byte occurrences). RF038–041 separately measured six original versus three native echo polls and opposite source/native same-local-age F6 incoming read ordering. RF042's attempted equal-age queue correction **regressed** strict WRAM, so it remains rejected.

## Causal acceptance/stop rules

A matching original raw pointer observation is **not** itself proof of equivalent instruction completion time or CPU-port/SPC delivery; require original executed `LDA` and subsequent `STA 2143/2142` correlation, an independently registered clock axis and real consumer before a timing patch. If the source DP mirror assumption or bounded sample misses the target, explicitly report *missing source consumer coverage*, not a byte mask, accepted event or sound bug. If the real original consumer disagrees at a separately qualified source/native instruction phase, only then consider a minimal source-backed runtime A/B using unmodified controller input and all strict Zoo, Bowl, SRAM, audio and negative event controls. Do not overwrite independent QA-01 or `docs/RELEASE-QUALITY-LEDGER.json`.
