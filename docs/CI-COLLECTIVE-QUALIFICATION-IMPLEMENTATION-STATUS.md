## What should be optimized: turnaround and evidence, not fictitious bills

The repository's [GitHub metadata](https://github.com/gamesbyian/UR-Recomp) reported **public** visibility at this snapshot. GitHub explicitly states [standard GitHub-hosted runners are free for public repositories](https://docs.github.com/en/actions/concepts/billing-and-usage); [larger runners may be billed](https://docs.github.com/en/billing/reference/actions-runner-pricing). GitHub also [postponed the proposed new self-hosted Actions charge](https://github.blog/changelog/2025-12-16-coming-soon-simpler-pricing-and-a-better-experience-for-github-actions/). Therefore the measured cancelled-job durations do **not** represent proven cash savings, and ordinary public-repo hosted Linux/Windows minutes should not be assigned fictitious pay-as-you-go charges. Separately watch artifact/cache storage policy, any actual premium-runner use, self-hosted HP electricity and real out-of-pocket services. Recheck billing docs and visibility if either changes.

Optimize **time to independently accepted product outcomes**, complete exact-source checks, ready-PR-to-merge latency, Windows critical path, developer contention and avoidance of superseded checks. Preserve cheap immediate feedback where it reduces defects; batching that merely hides test failures or holds a qualified PR is counterproductive.

The observed first candidate's hosted full tooling-plus-hygiene **recorded step spans** were **6.299 minutes across its two separate PR heads versus 2.733 minutes on the one frozen combined head**, a **3.566-minute hypothetical substitution difference**. **Realized savings were zero**, since all six runs actually happened. PR head test discovery was 7,131 on each individual versus 7,135 combined; caching, queues, source epochs and exact case identity were not controlled. A 382-second GitHub job-start-to-first-step gap on one individual head shows why raw job spans cannot be equated with runner consumption. Full retrospective: [plan comment](https://github.com/gamesbyian/UR-Recomp/pull/3141#issuecomment-6671500113).
